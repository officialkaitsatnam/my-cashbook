# My Cashbook — GitHub Pages

## Features
- Credit / Debit / Cash Balance dashboard
- Month & Year filter
- Fast lookup/search
- Add, edit and delete transactions
- Automatic running balance
- JSON Export / Import backup
- Responsive mobile + desktop layout
- Data stays in the browser using localStorage

## GitHub Pages
Upload all files to a GitHub repository, then:
Settings → Pages → Deploy from branch → main → /root → Save.

No server/database is required for this version.
